## About The Project
The goal of the project is to implement a memory hierarchy simulation that processes configuration data, validates it, and provides detailed statistics and trace information about memory operations. The main functions of the code are:
- printConfig: Validates and pretty prints the configuration of the memory hierarchy components (e.g., TLB, page tables, data cache, L2 cache).
- printInfo: Prints detailed trace information about memory operations
- calcRatio: Calculates the ratio of hits to the total of hits and misses
- printStats: Prints simulation statistics, including hit/miss counts and their ratios for various components
- printData: Represents a single memory trace entry with attributes for various memory hierarchy components
